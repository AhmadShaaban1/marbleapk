# تطبيق إدارة الرخام والجرانيت (Android)

يعمل **بدون إنترنت** بالكامل. البيانات محفوظة على الموبايل.

## بناء ملف الـ APK

### الطريقة 1: GitHub Actions (أسهل — بدون تنصيب أي حاجة)
1. اعمل مستودع (Repository) خاص على GitHub وارفع محتويات هذا المجلد.
2. من تبويب **Actions** اختر **Build APK** ثم **Run workflow**.
3. بعد ~5 دقائق نزّل الملف `marble-erp-apk` (جواه `app-debug.apk`) وثبّته على الموبايل.

### الطريقة 2: على جهازك
المتطلبات: Node 20+ و JDK 21 و Android Studio (أو Android SDK).
```
npm install
npx cap sync android
cd android && ./gradlew assembleDebug      # Windows: gradlew.bat assembleDebug
```
الناتج: `android/app/build/outputs/apk/debug/app-debug.apk`
(أو افتح مجلد `android` في Android Studio ← Build ← Build APK).

## أول استخدام
1. على أول جهاز: أنشئ حساب **المدير** (اسم المصنع + الاسم + رقم سري).
2. **المزيد ← المستخدمين**: أضف مشغل التقطيع والمبيعات (لكل واحد رقم سري).
3. **المزيد ← المزامنة ← تصدير** وابعت الملف (واتساب مثلًا) للأجهزة الأخرى، وعليها اختر **استيراد ملف مزامنة** من شاشة الدخول.
4. كل ما تحب تجمّع البيانات: كل جهاز يصدّر ملفه، والباقي يستورده. الدمج آمن (آخر تعديل لكل سجل يكسب، ولا يتم حذف شيء).

## الصلاحيات
| الدور | يشوف ويعمل |
|---|---|
| مدير | كل حاجة: التكاليف، الأرباح، المصروفات، التقارير، المستخدمين |
| مشغل تقطيع | البلوكات، تسجيل التقطيع، المخزون، مسح QR (بدون أسعار وتكاليف) |
| مبيعات | المخزون، الفواتير، العملاء، استلام الدفعات (بدون تكاليف) |

## دورة العمل
شراء بلوك ← تسجيل تقطيع (جنج سو/بلوك كاتر) وإنشاء الألواح بأكواد QR ← مخزون ← فاتورة بيع (اختيار أو مسح QR) ← تحصيل ← تقارير.
التكلفة = سعر البلوك + نقل + مصروفات التقطيع + أي مصروف محمّل على البلوك، وتتوزع على الألواح حسب المساحة.
